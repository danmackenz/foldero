# Project Scaffold Templates

Parametrised skeletons Artifex fills with user-provided values only. `{{var}}` = required input from the interview phase; `[optional: ...]` = included only if the matched archetype calls for it. No Dan-specific defaults anywhere in this file.

Token budget: 200 words per template (per SUITE-CONVENTIONS token-budget convention, §16).

## CLAUDE.md template
```markdown
# CLAUDE.md — {{project_name}}

**Purpose:** {{one_sentence_purpose}}
**Owner:** {{owner_name}}
**Sensitivity tier:** {{tier_1_2_or_3}}

## Structure
{{folder_tree_from_matched_archetype}}

## Rules
{{archetype_specific_rules}}

[optional: ## Restricted content
{{restricted_domain_note}}]
```

## AGENTS.md template
```markdown
# AGENTS.md — {{project_name}}

Agent/skill-specific operating notes for this project, distinct from CLAUDE.md's human-facing rules.

## Available automations
{{agent_or_skill_list}}
```
